01

What Midas is

Midas is a from-scratch rebuild of a Kalshi prediction-market trading bot. The previous bot reached ~5,300 lines in one Python file with multiple structural bugs (bankroll only goes up, dead reconciliation, dead strategies). The audit synthesis documented those failures. The architecture v2 document committed to a multi-service event-driven system inspired by hedge fund OMS/EMS/Risk separation.

Midas is being built deliberately, slowly, and well — explicitly avoiding the patterns that broke the old bot. The 10 lessons from docs/LESSONS_FROM_OLD_BOT.md are binding constraints, not suggestions.

The 10 binding constraints

From docs/LESSONS_FROM_OLD_BOT.md. If a proposal violates one of these, push back, name the lesson, suggest the alternative, ask before proceeding.

  1. Bankroll only goes up — use event sourcing, not mutable balance fields
  2. Reconciliation never ran — must be on a scheduler
  3. Strategies as strings — use ClassVar + __init_subclass__ enforcement
  4. Eight strategies, two of which were dead code — delete what isn't deployed
  5. Risk gates duplicated in eight places — one canonical implementation only
  6. Shadow drifted into research lab — paper environment ≠ research
  7. State file 34 keys deep with no schema — Pydantic + JSON Schema, versioned
  8. The learning system never learned — every event has a reader
  9. Magic numbers everywhere — config in YAML, not code
  10. The bot grew faster than its tests — tests not optional, CI gates

Common commands reference

From the laptop

cd ~/code/midas # Peter cd ~/Desktop/midas # Filippo git pull make install # Sync workspace deps make test # Run all 22 tests make lint # Run ruff make format # Auto-format KUBECONFIG=~/.kube/config-midas kubectl get nodes KUBECONFIG=~/.kube/config-midas kubectl get pods -A KUBECONFIG=~/.kube/config-midas kubectl get applications -n argocd KUBECONFIG=~/.kube/config-midas kubectl logs -n hello-svc -l app=hello-svc --tail=50

Re-seal a credential for a new namespace (safe stdin pipeline, no plaintext on disk)

printf '%s' "$(pbpaste)" | KUBECONFIG=~/.kube/config-midas kubectl create secret generic <name> \ --namespace <ns> --from-file=<ENV_VAR>=/dev/stdin --dry-run=client -o yaml | \ KUBECONFIG=~/.kube/config-midas kubeseal --controller-namespace=sealed-secrets \ --controller-name=sealed-secrets-controller --format=yaml > deploy/secrets/<ns>/<name>.yaml # Then clear clipboard, apply, decode-verify byte length: echo -n "" | pbcopy KUBECONFIG=~/.kube/config-midas kubectl apply -f deploy/secrets/<ns>/<name>.yaml KUBECONFIG=~/.kube/config-midas kubectl get secret <name> -n <ns> \ -o jsonpath='{.data.<ENV_VAR>}' | base64 -d | wc -c

Subscribe to NATS heartbeats (verifying a service is publishing)

KUBECONFIG=~/.kube/config-midas kubectl run nats-sub-test --rm -i --restart=Never \ --image=natsio/nats-box:latest -n nats -- \ nats sub --server=nats://nats:4222 'events.heartbeat.>' --count=1 --timeout=90s
